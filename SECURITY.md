# Security policy

mailcow-mcp handles mail credentials and gives agents access to a mailbox, so security reports
are very welcome.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through
[GitHub security advisories](https://github.com/nitramxx/mailcow-mcp/security/advisories/new).
Include the affected version, your configuration (without secrets), and steps to reproduce.

You should get a first response within 7 days. Once a fix is released, the advisory is published
with credit to the reporter, unless you'd rather stay anonymous.

## Supported versions

Before 1.0, only the latest release gets security fixes.
